# OTA 가격 역산 계산기

에어비앤비 · 부킹닷컴 · 트립닷컴에 한 숙소를 동시 운영할 때, 채널별 수수료율과 프로모션 할인율이 달라도 **원하는 순수익**을 기준으로 각 채널의 게시가를 역산해주는 정적 웹 계산기입니다.

빌드 도구 없이 순수 HTML/CSS/JS로 작성되어 Vercel(또는 아무 정적 호스팅)에 그대로 배포할 수 있습니다.

## 기능

- 평일/주말 목표 순수익(1박당 실수령액)과 월 평균 판매 박수 입력
- 플랫폼별 수수료율, 프로모션(복수 추가/삭제 가능) 입력
- 프로모션 적용 방식: 에어비앤비·부킹닷컴은 **곱연산**(차례로 적용), 트립닷컴은 **합산**(할인율을 더해 한 번에 적용)
- 플랫폼별 **가중치(%)**: 에어비앤비를 주력 채널로 쓰고 싶을 때 부킹닷컴/트립닷컴 가중치를 올리면 해당 채널 게시가가 더 비싸지고, 실제 예약 시 목표 순수익보다 가중치만큼 더 벌게 됨
- 채널별 게시가 / 게스트 결제가 / 실제 순수익 표
- 채널별 월간·연간 순수익 비교 (그 채널 하나로 월 판매 박수를 전부 채웠다고 가정했을 때 기준)
- 한국 개인사업자 기준 부가가치세·종합소득세·지방소득세 추정, 기준 채널의 연매출에 따라 간이과세자/일반과세자 자동 판정, 경비율은 국세청 업종코드 551007(공유숙박업) 단순경비율(84.6%)/기준경비율(17.3%) 중 선택
- 모바일 화면 대응 (반응형 레이아웃)

## 계산 방식 요약

```
결합할인율(곱연산) = 1 - (1 - 할인1) × (1 - 할인2) × …
결합할인율(합산)   = 할인1 + 할인2 + …
게시가 = 목표순수익 / [(1 - 수수료율) × (1 - 결합할인율)] × (1 + 가중치)
게스트 결제가 = 게시가 × (1 - 결합할인율)
실제 순수익 = 게스트 결제가 × (1 - 수수료율)  =  목표순수익 × (1 + 가중치)
```

세금은 기준 채널의 연간 실제 순수익을 매출로 보고, 매출이 1억 4백만원 미만이면 간이과세자(업종 부가가치율 25% 가정), 이상이면 일반과세자(매출/1.1을 공급가액)로 자동 판정해 부가세를 추정합니다. 사업소득금액(공급가액 × (1-경비율))에 종합소득세 누진세율을 적용하고 지방소득세(10%)를 더합니다. 경비율(2023년 귀속 고시 기준)은 국세청이 매년 갱신하므로 최신 고시를 확인하세요.

⚠️ **참고용 추정치입니다.** 실제 수수료·프로모션 조건은 각 플랫폼 호스트센터에서, 세금은 세무사와 반드시 확인하세요. 부킹닷컴/트립닷컴 계약상 레이트 패리티(최저가 보장) 조항이 있는지도 확인 후 채널별 가격 차등을 적용하세요.

## 로컬 실행

빌드 없이 정적 파일만 있으면 됩니다.

```bash
npx serve .
# 또는
python -m http.server 8080
```
