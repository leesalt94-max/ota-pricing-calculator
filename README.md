# 레이트 데스크 — OTA 채널별 가격 계산기

에어비앤비 · 부킹닷컴 · 트립닷컴에 한 숙소를 함께 올릴 때, 에어비앤비 가격(또는 원하는 순수익)을 기준으로 다른 채널 게시가와 한 달·1년 수익, 세금까지 단계별로 계산하는 정적 웹 계산기입니다.

빌드 도구나 외부 라이브러리 없이 `index.html` 파일 하나로 동작합니다. 설정값은 브라우저(localStorage)에만 저장됩니다.

## 사용 흐름

1. **시작 방식 선택** — 에어비앤비 평일 가격부터 / 원하는 순수익부터 (하단 '설정' 버튼에서 수수료·프로모션·운영 비용 설정)
2. **금액 입력** — 평일 금액 하나, 주말은 평일 대비 % 또는 직접 입력
3. **결과 요약** — 평일/주말 채널별 게시가 · 순수익
4. **더 알아보기** (필요한 것만 선택)
   - 가격 계산 과정: 게시가 → 할인 → 게스트 결제가 → 수수료 → 순수익
   - 인원 추가 요금: 에어비앤비 1인당 추가요금 기준으로 다른 채널 1인당 추가요금 역산, 인원별 게시가 표
   - 청소비: 채널별로 게스트에게 받는 청소비를 직접 입력(0원이면 미징수), 청소비 → 수수료 → 내 몫 → 청소 인건비 차감 후 1회당 남는 돈, 한 달 청소 횟수 = 판매 박수 ÷ 평균 숙박일수(반올림)
   - 한 달 · 1년 실제 수익과 세금: 월 판매 박수, 기준 채널 선택, 수수료·운영 비용·세금까지 뺀 실제 수익

설정(처음 화면 하단): 기본/결제대행 수수료, 프로모션 추가·삭제·켜고 끄기, 부킹·트립 가중치, 운영 비용(매달 / 1년 / 청소 1회 단위, 추가·삭제), 평균 숙박일수, 반올림 단위. 화면 아래 '이대로 저장'을 눌러야 저장되고, 저장하지 않고 나가면 변경이 취소됩니다. '기본값으로 되돌리기'는 설정 항목만 기본값으로 불러옵니다(저장해야 적용).

## 계산 방식

```
게스트 결제가 = 게시가 × (1 − 결합할인율)
순수익       = 게스트 결제가 × (1 − 기본 수수료 − 결제대행 수수료)

결합할인율 — 에어비앤비·부킹닷컴(곱연산): 1 − (1 − 할인1) × (1 − 할인2) × …
           — 트립닷컴(합산):            할인1 + 할인2 + …

다른 채널 게시가 = 에어비앤비 순수익 × (1 + 가중치) ÷ [(1 − 결합할인율) × (1 − 수수료)]
```

정산 방식 차이 — 부킹닷컴: 기본 수수료 15% + 결제대행 2.5%가 할인 후 객실 요금과 청소비를 합한 금액에 붙음. 트립닷컴: 수수료 15%가 할인 후 객실 요금에만 붙고 청소비는 수수료 없이 그대로 들어옴(트립닷컴이 부담하는 쿠폰은 정산액에 영향 없음). 에어비앤비: 호스트 수수료가 객실 요금과 청소비에 붙음.

가격은 설정한 반올림 단위(기본 100원)로 맞춥니다. 인원 추가 요금은 프로모션 할인이 추가 요금에도 적용된다고 가정합니다. 청소비는 채널별 입력값을 그대로 쓰며 매출에 포함됩니다. 수수료는 에어비앤비·부킹닷컴만 청소비에 붙고 트립닷컴은 붙지 않습니다(할인은 기본 미적용). 청소 인건비는 운영 비용의 '청소 1회' 항목으로 뺍니다.

### 세금 (참고용 추정)

- 연 매출 = 기준 채널의 **게스트 결제액**(부가세 포함 가정)
- 과세유형: 연 매출 1억 4백만원 미만 간이과세자(숙박업 부가가치율 25%, 4,800만원 미만 납부면제), 이상 일반과세자(매출 ÷ 1.1 = 공급가액)
- 소득세 수입금액 3,600만원 미만: 단순경비율 84.6%
- 3,600만원 이상: 기준경비율 — 소득 = 수입 − 주요경비('증빙 있음' 운영 비용: 임차료·인건비·매입비용) − 수입 × 17.3%. 플랫폼 수수료는 주요경비가 아니므로 따로 빼지 않음. 단, 소득은 단순경비율 소득 × 2.8배(간편장부대상자, 복식부기의무자 3.4배)를 넘지 않음(소득세법 시행령 제143조)
- 사업소득금액에 종합소득세 누진세율, 지방소득세 10%
- 무기장가산세: 기준경비율로 신고하고 1년 매출(직전연도, 매년 비슷하다고 가정)이 4,800만원 이상이면 산출세액의 20% 추가
- 운영 비용(월 환산) = 매달 비용 + 1년 비용 ÷ 12 + 청소 1회 비용 × 청소 횟수
- 증빙 있는 비용에 '원천징수 3.3%'를 켜면 입력액을 받는 분 실수령액으로 보고, 실제 비용 = 입력액 ÷ (1 − 0.033) (예: 50,000원 → 51,706원). 기본은 꺼짐
- 실제 수익(세후) = 게스트 결제액 − 플랫폼 수수료 − 운영 비용 − 부가세 − 종합소득세 − 지방소득세

경비율은 국세청 업종코드 551007(공유숙박업) 2023년 귀속 고시 기준이며 매년 바뀝니다. 실제 단순경비율 판정은 직전연도 수입금액 기준이고, 장부를 작성하면 다른 비용도 인정됩니다. 실제 세액은 세무사와 확인하세요. 부킹닷컴·트립닷컴 계약상 레이트 패리티(최저가 보장) 조항도 확인 후 채널별 가격 차등을 적용하세요.

## 비교판 (`/board`)

`board/index.html` — PC 한 화면에서 에어비앤비 · 부킹닷컴 · 트립닷컴 카드 3장을 나란히 비교하는 새 화면입니다. 배포 주소: `/board`

- 어느 카드든 평일 · 주말 게시가를 입력하고 칸을 벗어나면(또는 Enter) 그 OTA가 기준이 되고, 나머지 OTA 가격이 **월 최종 순수익(세후)** 이 같도록 자동으로 맞춰집니다. 다른 OTA의 주말가는 기준 OTA의 주말/평일 비율을 따릅니다.
- 게시가 아래 **1박 순수익 −1,000 / +1,000** 버튼: 누를 때마다 그 카드의 평일(또는 주말) 1박 순수익이 1,000원씩 바뀌도록 게시가를 역산하고, 그 카드가 기준이 되어 다른 OTA 가격 · 게스트 결제가 · 월 순수익이 함께 바뀝니다.
- 가중치: OTA별로 가중치 0% 기준보다 순수익을 몇 % 더 남길지 정합니다 (에어비앤비 100만원 → 부킹 5% 105만원).
- 프로모션은 카드 안에서 켜기/끄기(막바지 할인 15%는 기본 꺼짐) · 수정 · 추가 · 삭제. 에어비앤비 · 부킹닷컴은 곱연산, 트립닷컴은 합산.
- 청소비(기본 5만원), 1인 추가 요금(4명 기준, OTA마다 따로 입력 · 연동 없음), 한 달 평균 추가 인원, 인원 선택 시 게스트 결제액 · 1박 순수익, 1~4박 숙박 예시.
- 월 수익 내역: 게스트 결제 총액 → 플랫폼 수수료 → 월세 / 공과금·기타 / 청소 → 부가세 → 종합소득세 + 지방세 → 월 최종 순수익. 세금 계산은 아래 '세금' 항목과 같습니다. 월 순수익은 한 달 판매 박수를 그 OTA에서 모두 팔았다고 보고 계산합니다.
- 월세 · 공과금 · 판매 박수는 상단 '월 운영 설정'에서 바꿉니다. 운영 비용은 단위가 '청소 1회'면 청소, 이름에 월세 · 임대 · 임차가 있으면 월세, 나머지는 공과금 · 기타로 묶어 보여 줍니다.
- 입력값은 브라우저(localStorage, `rate-board-v8`)에만 저장됩니다.

트립닷컴 계산 (게스트 화면 '요금 정보'와 관리자 '요금 명세'로 확인):

```
게스트 객실 결제 = 게시가(부가세 포함) × (1 − Σ숙소 부담 할인) × (1 − 트립 쿠폰)
부가가치세 표기   = 게스트 객실 결제 ÷ 11       (객실 요금 표기 = 게시가 − 부가가치세)
정산(지급액)      = 게시가 × (1 − Σ숙소 부담 할인) + 청소비   ← 트립 쿠폰(특별 할인)은 정산에 영향 없음
내 순수익         = 지급액 − 객실 요금 × 수수료 15%  ← 청소비에는 수수료 없음 (요금 명세에 수수료 줄이 없어 가정)
```

## 로컬 실행 · 배포

`index.html`을 브라우저로 바로 열면 됩니다. Vercel은 이 저장소에 연결되어 있어 `main` 브랜치에 푸시하면 자동 배포됩니다(Framework Preset: Other, 빌드 명령 없음).
